# Three-minute hackathon demo

**0:00–0:20 — Frame the problem.** “Students jump between job boards and spreadsheets. They need to know not just what exists, but why it fits, what evidence supports it, and what they must do next.”

**0:20–0:45 — Search.** Search “AI internship” or “Python developer”. Point out the explicit Demo Mode label if no key is configured. With a real key, show the Live SerpApi label and explain that the key stays on the backend.

**0:45–1:15 — Explainable match.** Open a result. Show compatibility score, skills matched, skills missing, role and location reasons. Say “This is not a probability of being hired.”

**1:15–1:45 — Evidence & Trust.** Point out application URL, deadline, source and freshness. Demonstrate missing/unknown states. Explain that Google Jobs does not independently verify each employer and Hermes does not invent deadlines or scam scores.

**1:45–2:20 — Application tracker.** Save a result and open Applications. Change its status. In the full demo API, application notes and date fields persist in the database. Refresh the page to show persistence.

**2:20–2:45 — Digest and analytics.** Open Daily digest and Analytics. Explain deterministic ranking and that counts come from tracker records.

**2:45–3:00 — Close.** “Hermes turns discovery into a trustworthy workflow: find opportunities, inspect evidence, understand fit, track actions, and watch deadlines.”

## Before presenting

- Configure a valid SerpApi key if you intend to demonstrate live results.
- Test the venue's network and API quota.
- Create a demo account and complete the profile before the presentation.
- Keep demo mode clearly labelled if no live key is configured.
- Do not claim that an example job is real or verified.
